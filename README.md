# 💅 Estética Prizzy Muniz

Um website responsivo e moderno para um salão de estética, desenvolvido com HTML5 e CSS3.

## 📋 Sobre o Projeto

A Estética Prizzy Muniz é um projeto de website profissional para um salão de beleza, apresentando informações sobre serviços e criando uma presença online elegante e atrativa.

## ✨ Características

- 🎨 Interface limpa e moderna
- ✅ Estrutura HTML semântica
- 🎯 Identidade visual profissional
- 📸 Galeria de imagens otimizada

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização e layout responsivo

## 📁 Estrutura do Projeto

```
estetica-prizzy-muniz/
├── index.html                 # Página principal
├── style.css                  # Estilos globais
├── Assets/                    # Imagens e recursos
└── Identidade Visual.pdf      # Guia de marca
```

## 🚀 Como Usar

### Pré-requisitos
- Navegador web moderno (Chrome, Firefox, Safari, Edge)

### Visualizar o Projeto

1. Clone o repositório:
```bash
git clone https://github.com/BrunoRivaroli/estetica-prizzy-muniz.git
```

2. Abra o arquivo `index.html` em seu navegador

3. Ou acesse a versão online: [GitHub Pages](https://brunorivaroli.github.io/estetica-prizzy-muniz/)

## 📸 Visualização

O website apresenta:
- Página de boas-vindas elegante
- Seções com informações sobre serviços
- Galeria de fotos
- Informações de contato
